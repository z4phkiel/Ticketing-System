# IT knowledge base

The AI may answer tickets only from these articles. Edit this file to change what it knows.

## Accounts and passwords

**Forgot your password.** On the sign-in screen click "Forgot password?", enter your work email, and
follow the link we send. The link expires after 1 hour. Check your spam folder if it does not arrive
within 5 minutes.

**Account locked after too many attempts.** Wait 15 minutes; the lock clears by itself. Then sign in
with your correct password, or reset it with "Forgot password?".

**Caps Lock and keyboard layout.** If your password is rejected, check that Caps Lock is off and that
the keyboard language (shown at the bottom right of the Windows taskbar) is the one you normally use.
Press Windows key + Space to switch layouts.

## Network and internet

**Wi-Fi not connecting.** 1) Turn Wi-Fi off and on from the taskbar network icon. 2) Choose the network,
select "Forget", then connect again and re-enter the password. 3) Restart the computer. 4) Check that
Airplane mode is off. If other devices also have no internet, the network itself may be down.

**Connected but no internet.** Restart the computer. On Windows, open Settings > Network & internet >
Advanced network settings > Network reset if restarting does not help. Try a different website to rule
out one site being down.

**VPN will not connect.** Check that you have internet first. Close the VPN app fully (right-click its
icon > Quit), open it again, and sign in. Make sure the computer's date and time are correct
(Settings > Time & language > Set time automatically).

## Computer performance

**Computer is slow.** 1) Restart it (shut down fully, not sleep). 2) Close programs and browser tabs you
are not using. 3) Open Task Manager (Ctrl + Shift + Esc) and look for programs using a lot of CPU or
memory. 4) Make sure at least 10% of the disk is free.

**Disk is full.** Empty the Recycle Bin, clear the Downloads folder, and run Disk Cleanup (search for
"Disk Cleanup" in the Start menu). Settings > System > Storage shows what is using space.

**Windows updates.** Go to Settings > Windows Update > Check for updates, install them, and restart.
Many problems are fixed by installing pending updates. Updates can take 10-30 minutes; keep the
computer plugged in.

**Computer frozen.** Press Ctrl + Alt + Delete and open Task Manager to end the program that is not
responding. If nothing responds, hold the power button for 10 seconds, wait, then turn it back on.
Unsaved work may be lost.

## Printers and devices

**Printer not printing.** 1) Check it is on, has paper, and shows no error light. 2) On the computer, open
Settings > Bluetooth & devices > Printers & scanners, select the printer, and open the print queue;
cancel stuck jobs. 3) Turn the printer off and on. 4) Make sure it is set as the default printer.

**Second monitor not detected.** Check both ends of the cable and that the monitor is on the correct
input. Press Windows key + P and choose "Extend" or "Duplicate". In Settings > System > Display, click
"Detect".

**Mouse or keyboard not working.** For wireless devices, replace or charge the batteries and turn the
device off and on. For USB devices, try a different USB port. Restart the computer.

**No sound.** Click the speaker icon on the taskbar and check the volume and the selected output device.
Unplug and replug headphones. Restart the computer.

## Email and software

**Outlook not receiving email.** Check you are online, then close and reopen Outlook. Look at the bottom
of the window for "Working offline" and turn it off (Send / Receive > Work Offline). Check the Junk
folder.

**Program will not open or keeps crashing.** Restart the computer, install updates for the program, and
try again. If it still fails, note the exact error message and submit a ticket.

**Installing new software.** Install approved software from the Company Portal app (search for it in the
Start menu). For software that is not listed, submit a ticket saying what you need and why; IT will
review the request.

**Browser problems (pages not loading, odd layout).** Refresh the page, then try a private window. If
that works, clear the browser cache: press Ctrl + Shift + Delete, choose "Cached images and files", and
clear it.

## Always handled by a technician

Viruses or malware, phishing emails you clicked or replied to, hacked or compromised accounts,
suspicious sign-ins, two-factor authentication lockouts, lost or stolen devices, physical damage
(spills, drops, broken screens), computers that will not turn on at all, data loss or file recovery,
and outages affecting many people.
